# MarketPro - Digital Marketing Platform

A turnkey, all-in-one digital marketing agency management platform built with Ruby on Rails.

## Features

- **Client CRM** - Manage clients, contacts, contracts, and retainers
- **Campaign Management** - Track campaigns across SEO, PPC, Social, Email, Content, Display, and Affiliate channels with full metrics (impressions, clicks, conversions, revenue, ROI)
- **Content Calendar** - Plan, schedule, and publish content across 9+ platforms with a visual monthly calendar view
- **Lead Pipeline** - Kanban-style pipeline with 7 stages, lead scoring, value tracking, and one-click stage advancement
- **Task Management** - Priority-based task tracking with categories, due dates, time estimates, and team assignment
- **Analytics Dashboard** - Real-time KPIs, campaign performance, pipeline overview, and channel breakdowns
- **Client Reports** - Generate monthly, weekly, campaign, and custom reports with auto-calculated metrics
- **Team Management** - Role-based access (Admin, Manager, Team Member) with activity tracking
- **Activity Feed** - Automatic tracking of all actions across the platform

## Setup

```bash
bundle install
rake db:migrate
rake db:seed
rails server
```
